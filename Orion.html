Orion 2.1.0
2026-11-22 · 桌面版（Electron 35 / Windows x64）
当前版本

2.1.0 主要变化

  • 「工作任务」升级为本机代理：模型可以自己调用 PowerShell 命令、读写与修改工作区文件、列目录、全屏截屏、点击鼠标、键入文字、发送快捷键、启动程序，逐步执行到任务完成。
  • 新增三档权限：只读、工作区写入（默认）、完全访问。权限在主进程强制执行，不是界面提示；越权读写、危险命令（关机、格式化、批量删除、注册表删除等）会被直接拒绝。
  • 任务卡片实时显示思考、工具调用、执行结果与错误，支持中途停止（连带杀掉子进程）、清除已结束任务、展开查看完整步骤。
  • 工作区固定在安装目录的 workspace，路径监狱按绝对路径校验，禁止用 .. 逃出；截屏与鼠标键盘操作仅完全访问可用。
  • 命令执行带超时与进程树清理，输出过长的自动截断；单次任务最多 12 步，防止无限循环。
  • 修复打包后缺少 preload 导致任务代理不可用的问题。
  • 数据目录从安装目录迁到 %APPDATA%\Orion，覆盖安装或卸载不再清空聊天记录、Key 与设置；旧数据首次启动自动迁移。

2.0.0 主要变化

  • 全新自主品牌与视觉：自绘星座环形标记、全新配色与字标，不再使用任何第三方标识、图标或界面素材。
  • 新增「工作任务」入口（2.1.0 起改版本机代理，见上）。
  • 设置新增「更新说明」与「用户协议」两页，协议中明确非官方客户端与数据处理方式。
  • 保留全部既有能力：附件上传与粘贴、OCR 文字识别、语音输入、语音朗读、联网搜索、上下文保留与缓存。

1.1.0

  • 省 token 的用户侧开关：上下文保留 6/12/24 轮或全部，默认 12 轮。
  • 历史总字数上限 24000、附件识别结果 6000 字、搜索结果 5000 字，超出自动截断。
  • 同一文件、同一问题的识别与搜索走会话内缓存，不重复计费；输入超过 2 万字先截断提示。
  • OCR / 语音 / 搜索的 token 一并计入额度消耗。

1.0.0

  • 首个正式安装包：Electron 桌面客户端、NSIS 安装器、桌面与开始菜单快捷方式。
  • 附件上传、粘贴图片、OCR、语音识别、语音合成、联网搜索全部接通真实接口。
  • 侧栏实时余额与可用 token 估算。

更新方式

运行新版安装包覆盖安装即可，聊天记录、Key 与设置保存在安装目录下的 data 文件夹，不会随升级丢失。

用户协议与隐私说明
生效日期 2026-11-22 · 适用于 Orion 桌面客户端

一、软件性质

Orion 是个人自建的本地桌面客户端，仅用于连接用户本人选择的 AI 服务接口。本软件与深度求索（DeepSeek）及其关联主体没有任何隶属、代理或合作关系，不代表其官方立场，也不是官方客户端。

软件中出现的第三方名称、模型标识仅用于说明所调用的接口与模型，相关商标、名称权利归各自权利人所有。

二、账号与费用

  • 你需自行在服务商开放平台注册并获取 API Key，自行承担接口调用产生的费用。
  • Key 仅保存在本机的用户数据目录 %APPDATA%\Orion，不上传、不经过本软件作者的任何服务器。
  • 余额与 token 数为按服务商接口返回值换算的估算，最终以服务商账单为准。

三、数据处理

  • 对话记录、工作任务、设置项默认保存在本机，卸载默认不删除。
  • 你发送的文字、图片、文件会提交给你配置的接口服务商处理，请遵守该服务商的条款与隐私政策。
  • 附件识别、语音识别与语音合成会将对应内容上传至接口方；涉密、敏感或个人隐私内容请勿提交。

四、使用规范

  • 不得使用本软件生成、传播违法信息，或侵害他人合法权益的内容。
  • 不得将本软件用于转售接口、代充值、批量账号操作等违反服务商条款的行为。
  • 不得移除或伪造品牌标识后对外冒充任何官方产品发布。

五、本机操作与风险

  • 「工作任务」具备在本机执行命令、修改文件、截屏与操作鼠标键盘的能力，属于高风险功能，默认只开放工作区写入与安全命令。
  • 切到「完全访问」后，模型可以执行任意 PowerShell 命令、读写工作区之外的文件、启动程序并操作桌面。由此产生的一切后果（包括数据被覆盖、软件被卸载、系统设置被修改）由使用者自行承担。
  • 执行前请确认任务目标描述准确；涉及删除、移动、覆盖的操作，请先让任务只做只读探查，核对路径后再授权写入。
  • 不要把 API Key、密码、身份证件等敏感信息写进交给任务的命令或文件内容。
  • 本软件不采集、不上传你的命令与执行结果；但这些内容会作为上下文发给所配置的模型接口，用于决定下一步操作。

六、免责

本软件按现状提供，不对模型输出的准确性、完整性、可用性作任何担保。因接口变更、网络故障、余额不足、内容违规导致的损失，由使用者自行承担。使用前请自行评估所在地区的法律与合规要求。
